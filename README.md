# Ashenfeild Rebirth — Source Recovery & Reconstruction

> **IMPORTANT: This is NOT the original DEAD ZONE: AFTERMATH v7.1 source repository.**

The original production game remains at https://dead-zone-ashford-3d.easyfirefly2.chatgpt.site/ and was reported as **v7.1, Site version 17**, linked to Sites commit `1c2eb8fbba4fc8587078c1608f6ddfdeac5146c2`. The original Sites Git checkout is not available here and its history has **not** been recovered.

## Repository layout
- `main` — placeholder and source-recovery notice. Reserved for the eventual genuine source migration.
- `reconstruction-prototype` — independent, original-code browser recreation of the opening-route concepts. It is **not** identical to the Sites game, and its commits must never be represented as the original Sites history.

To play the reconstructed prototype, switch to the `reconstruction-prototype` branch, or configure GitHub Pages to publish the branch from the repository root.

## Source recovery
If you recover the original Sites Git bundle, audit all history for credentials before importing, especially because this repository is currently public. Preserve the recovered source's original commit SHA and ancestry in a separate migration. Do not overwrite or silently conflate it with the reconstruction.

**No deployment to the original Sites production game is performed by this repository.**
